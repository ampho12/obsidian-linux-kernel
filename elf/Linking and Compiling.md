
| Artifact Type               | Compile-Time (baked-in fields)                      | Runtime (required / resolved)                                                                                                                                                                                         |
| --------------------------- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Binary (static)** `.elf`  | `symbols`, `text`, `data`, `relocs`                 | none                                                                                                                                                                                                                  |
| **Binary (dynamic)** `.elf` | `PT_INTERP`, `DT_NEEDED`, `RPATH/RUNPATH`, `SONAME` | - `loader/dynamic interpreter (e.g ld-linux)` (found via `PT_INTERP`)<br>- `.so` listed in (`DT_NEEDED`), but found via system paths + `RPATH/RUNPATH`                                                                |
| **Library (static)** `.a`   | `symbols`, `objects`, `archives`                    | none                                                                                                                                                                                                                  |
| **Library (dynamic)** `.so` | `DT_NEEDED`, `RPATH/RUNPATH`, `SONAME`              | `.so` names (listed in `DT_NEEDED`), but found via system paths + `RPATH/RUNPATH`, resolved by `loader`. <br>- These are not executed and hence don't need PT_INTERP. The binary that loads these provides the linker |
``

| Keyword                            | Description                                                                                                                                                                                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PT_INTERP**                      | Absolute path to the dynamic loader embedded in ELF binaries (e.g. `/lib64/ld-linux-x86-64.so.2`). The kernel reads this field and uses it to invoke `ld-linux` at program start.                                                           |
| **ld-linux**                       | The ELF dynamic loader specified in `PT_INTERP`. At runtime, it maps shared objects, resolves symbols, and applies relocations for all `DT_NEEDED` entries.                                                                                 |
| **DT_NEEDED**                      | Lists the names of required shared libraries (e.g. `libhidapi.so.0`, `libusb-1.0.so`). The loader uses these names to locate and load the libraries.                                                                                        |
| **RPATH / RUNPATH**                | Embedded search directories inside ELF files. The loader consults these paths when resolving `DT_NEEDED` libraries (after or before system paths, depending on loader version). `$ORIGIN` expands to the directory of the current ELF file. |
| **SONAME**                         | Logical name for a shared object (e.g. `libfoo.so.1`) that is stored in the ELF and used to match dependencies against `DT_NEEDED` entries.                                                                                                 |
| **symbols / text / data / relocs** | Static code and relocation data embedded directly into ELF sections — resolved fully at link time, not used at runtime.                                                                                                                     |
| **archives / objects**             | `.a` libraries are collections of `.o` files used by the linker; not involved in runtime resolution.                                                                                                                                        |
| **LD_LIBRARY_PATH**                | Environment variable that **overrides normal lookup order** by prepending its directories ahead of `RPATH/RUNPATH` and system paths when resolving `DT_NEEDED` libraries.                                                                   |
